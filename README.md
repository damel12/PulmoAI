# PulmoAI

Интерактивный тренажёр клинического мышления в пульмонологии для студентов и резидентов Казахстана.
Студент проходит кейс от жалоб до лечения, получает балл по рубрике и персональный разбор от ИИ-наставника.

## Запуск

```bash
npm install
npm run dev          # http://localhost:3000
```

Production-сборка: `npm run build && npm start`.

ИИ-разбор включается ключом Claude API:

```bash
cp .env.example .env.local   # и впишите ANTHROPIC_API_KEY
```

Без ключа тренажёр работает полностью, кроме кнопки «Получить разбор» — она сообщает, что ИИ не настроен.

## Проверки

```bash
npm test             # оценка ответов и целостность данных кейсов
npm run typecheck
```

## Устройство

| Путь | Что там |
|---|---|
| `src/lib/cases/` | Кейсы как данные. Новый кейс — новый файл по типу `ClinicalCase` + строка в `index.ts` |
| `src/lib/scoring.ts` | Детерминированная оценка по рубрике (веса, частичный балл за обследования) |
| `src/lib/review.ts`, `src/app/api/review/route.ts` | ИИ-разбор через Claude. Клиент присылает только id ответов, текст кейса и балл сервер берёт из своих данных |
| `src/lib/progress.ts` | Прогресс в `localStorage` — аккаунтов пока нет |
| `src/components/case/` | Движок кейса: шаги, вопросы, экран результата |
| `src/components/media/` | Схемы рентгена и ВРКТ с находками, ЭКГ, спирометрия, синтез аускультации |
| `prototype/` | Исходные HTML-прототипы, из которых вырос проект |

Балл всегда считает рубрика. ИИ его не меняет, а только объясняет ошибки на данных конкретного пациента.

## Ограничения текущей версии

- Снимки — учебные схемы, не реальные исследования.
- Содержание кейсов нужно проверить практикующим пульмонологом.
- Нет аккаунтов и серверного хранения; лимит запросов к ИИ — в памяти процесса (при нескольких инстансах нужен Redis).
